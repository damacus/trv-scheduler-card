🏠 TRV Heating Scheduler

Beautiful, Tado-inspired heating control for Home Assistant

What is this?

A custom Home Assistant card that gives you elegant, visual control over your smart radiator thermostats (TRVs). Create weekly heating schedules with different temperatures for different times of day, across multiple zones in your home.

Inspired by Tado's interface, designed for efficiency, built for the Home Assistant community.

📅

7-Day Scheduling

Different schedules for each day of the week. Perfect for varying routines between weekdays and weekends.

🎨

Visual Timeline

See your entire day's heating schedule at a glance with color-coded temperature blocks.

🏡

Multi-Zone Support

Control multiple rooms independently. Each zone gets its own schedule and settings.

📋

Copy & Paste

Quickly duplicate schedules across days. Set up Monday, then copy to the rest of the week.

🌡️

Temperature Control

Visual sliders make it easy to set exact temperatures for each time block.

📱

Mobile Optimized

Works perfectly on phones, tablets, and wall-mounted displays.

Quick Installation Guide

1

Download the Files

You'll need two JavaScript files:

  • trv-heating-scheduler-card.js
  • trv-heating-scheduler-card-editor.js
2

Upload to Home Assistant

Copy both files to your Home Assistant:

/config/www/trv-scheduler/ ├── trv-heating-scheduler-card.js └── trv-heating-scheduler-card-editor.js

Create the www/trv-scheduler/ directory if it doesn't exist.

3

Register the Resource

In Home Assistant:

  1. Go to Settings → Dashboards
  2. Click the ⋮ menu (top right)
  3. Select Resources
  4. Click + ADD RESOURCE
  5. URL: /local/trv-scheduler/trv-heating-scheduler-card.js
  6. Type: JavaScript Module
4

Restart Home Assistant

Go to Settings → System → Restart and restart Home Assistant.

5

Add the Card

On any dashboard:

  1. Click Edit Dashboard
  2. Click + ADD CARD
  3. Search for "TRV Heating Scheduler"
  4. Configure your zones and temperatures
  5. Save!

Example Configuration

Here's a basic setup for a two-room home:

type: custom:trv-heating-scheduler-card title: Heating Schedule zones: - id: living_room name: Living Room entities: - climate.living_room_trv - id: bedroom name: Bedroom entities: - climate.bedroom_trv default_temperature: 16 comfort_temperature: 19
